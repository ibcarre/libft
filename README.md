# libft

A C library developed as part of the 42 curriculum.

## Objective

Reimplement and organize utility functions to develop a deeper understanding of strings, memory management, and data structures in C.

## Contents

The library includes utility functions for string manipulation, memory operations, type conversions, and linked lists.

## Technologies

- C
- Memory management
- String manipulation
- Data structures

## Build

```bash
make
```
